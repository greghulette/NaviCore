Recorded servo tracks draw as a clean line — click ON the line to add a control point (it snaps to the curve), then drag it to reshape (nearby motion follows — see “Smooth drag”) · select a control point to reveal its two handle arms; drag a handle to bend the curve on that side (handle height = slope, distance = reach — Photoshop-style) · double-click-drag a dot to move just that one · right-click a dot to delete it (or Delete/Backspace, or 🗑) · “All points” shows the raw captured dots · + Action adds an action at the yellow cursor (or click the Actions lane); drag its diamond to move it in time, click to edit, right-click to delete — two actions on the same spot auto-nudge 5 ms apart · Shift-click two control points (no other control point between) for an easing pair · drag the yellow handle to scrub · red ✕ deletes a whole track · ✂ Trim start removes leading empty space; Length sets the clip's total time — raise it to add time at the end (each servo holds its pose out to the new end; drag those end points to animate) · Ctrl+scroll zooms at the pointer, ⤢ Fit fits · Overlay stacks every track into one lane in different colors to line curves up (dots/handles/add all still work); Normalize (on by default) scales each track to its own travel so same-joystick channels sit on top of each other — uncheck it for actual µs on one shared scale · click a track name on the left to focus it: it's highlighted, the rest fade, and new points go to it (great when tracks overlap); click it again to unfocus · ↶ Undo (Ctrl+Z) reverts the last edits (up to 50) · 〰 Smooth lightly smooths the FOCUSED channel's curve — click again for more (focus a track or select a dot on it first) · ⬇ Script exports the clip as Maestro script source (peaks/direction changes only, fits the Maestro's 8 KB script memory) — paste into Control Center's Script tab and trigger it with the "Run a script" action.

Logical Buttons

Matrix-channel logical buttons 15 extra buttons on matrix CH7, not on the transmitter graphic

Mix a transmitter logical switch (or any spare source) onto the matrix channel, then set the value it outputs below. When the matrix channel reaches that value (±10), the logical button fires — with the same per-mode, multi-tap actions as the physical buttons. Switch the mode tabs to map different actions per mode; Configure actions opens the standard editor. Leave the trigger blank to disable a slot.

Transmitter

Model which physical transmitter you're using

The model determines which SVG is displayed, which controls appear in calibration, and the default channel assignments for each control. Calibration still overrides per-control channels individually, so a custom TX mixer setup still works — the model just provides sensible starting points.

X20 hardware options

Check this if your X20 has the optional 3-axis gimbal upgrade — adds the J5 (left-stick twist) / J6 (right-stick twist) axes and the two stick-click momentary buttons (matrix slots 19 / 20) to the axes table, assignment list, and calibration walk. Leave unchecked on a standard 2-axis X20.

Maestro Locations

Defines where each logical Maestro lives. Buttons/knobs only pick "Maestro 1-8" and don't care about the wiring. Every physical Maestro must have a unique Pololu device # (0-127) set in Maestro Control Center — the value here must match it so only the addressed Maestro responds.
Import a Maestro's saved settings file (📁 button or drag-and-drop the file onto a row) to pull in that Maestro's real per-channel endpoints and names — they drive the passthrough ranges and the timeline editor.

Smoothing Profiles

A smoothing profile sets the Maestro speed and acceleration per servo channel. A joystick knob picks a profile (in its editor), and a Maestro "Apply smoothing profile" action or a script can load one — so the same servos can move gently or snappily on demand. Lower speed/accel = smoother. Enable a Maestro in the Maestro tab first, then add its channels here.

Baud Rates

Maestro (S2) = local Pololu Maestro bus (up to 115200). S3 runs on the hardware UART0 (both boards) so it can exceed 57600 (up to 115200); S4/S5 are bit-banged SoftwareSerial (≤57600). All are aux ports for HCR-local / MP3-local / Serial actions (one port = one device = one baud). On NaviCore v2 they're the silkscreen Serial 1/2/3; on WCB 3.2 they map to its Serial 3/4/5 headers. Reboot (or re-save) for changes to take effect.
